# Kit components

Generated by `render_kit/index.py` from the kit's docstrings. Don't edit it by hand: change the docstring and run `python3 skills/atlassian-design/render_kit/index.py`.

Every function here is exported by the package, so a renderer reaches it as `k.<name>` after `import render_kit as k`. Each family's CSS sits beside its module and is added to a page only when the page uses one of its classes. `tokens.css`, `ads.css`, `links.css` and `layout.css` are on every page. Don't add CSS for new visual pieces to a renderer: add them to the kit as components, with a docstring, and run this script.

## page

Page assembly and the command line: the stylesheet, the sprite, the page scripts, the mockup note and the
checks every page passes.

The stylesheet is tokens.css (with its dark list repeated under the prefers-color-scheme media query), ads.css,
links.css and layout.css, then every other .css file in this folder, in name order, whose classes the page
uses, then the renderer's own CSS.

### `page(title, body, css='', js='', width='reading', mockup=False)`

The whole self-contained HTML file: the kit's CSS, the renderer's CSS, the sprite and the scripts.

width is the page's max width: reading (760px, the default) for every text page, wide (880px) only for a page
whose diagram needs more room than reading gives (dependency-map), or board (1240px) for a work board. mockup
adds the sample data note at the top.

    k.page('Catch-up: Search migration', body, css=PAGE_CSS, mockup=d.get('mockup'))

### `unfilled(out)`

The {n} link placeholders left in the page's text, outside its CSS and script.

    unfilled(html)  # ["{1}"] when a text field had fewer links than placeholders

### `main(render, usage)`

The renderer's command line: data.json page.html. It renders, refuses unfilled placeholders and names
any missing key's path, for example `data error: people[1].evidence[0]: missing "link"`.

    if __name__ == '__main__':
        k.main(render, 'render.py card.json who-to-ask.html')

CSS: `links.css`, styling `.chip-placeholder`, `.found-label`, `.lozenge`, `.plain-ref`, `.smart-link`, `.smart-link--found`, `.smart-link__app`, `.smart-link__icon`, `.smart-link__icon--board`, `.smart-link__icon--bug`, `.smart-link__icon--database`, `.smart-link__icon--epic`, `.smart-link__icon--folder-closed`, `.smart-link__icon--goal`, `.smart-link__icon--page`, `.smart-link__icon--project`, `.smart-link__icon--project-status`, `.smart-link__icon--story`, `.smart-link__icon--subtasks`, `.smart-link__icon--task`, `.smart-link__icon--timeline`, `.smart-link__icon--video`, `.smart-link__icon--whiteboard`, `.smart-link__note`, `.smart-link__status`, `.smart-link__title`, `.visually-hidden`.

### `e(s)`

Escape a value for HTML text or an attribute. None is empty.

    e('Fix <b> tags')  # "Fix &lt;b&gt; tags"

### `link(l)`

A smart link. With no URL, it renders as plain text that says no link is available.

Data: {"title", "url", "icon", "app"?, "found"?, "status"?, "note"?}. `app` names a third-party app after
the title, `found: true` marks it Found by search, `status` is a lozenge after the title, and `note` is
subtle text inside the chip after the title, such as a recording's length or "No access".

    link({"title": "SRCH-412 Split facet fields", "url": "#", "icon": "task",
          "status": {"text": "In review", "tone": "information"}})

### `placeholder(label, ic)`

A muted, dashed chip that stands in for a missing object, such as "No notes". It isn't a link.

    placeholder('No recording', 'video')

### `links(x)`

One smart link or a list of them, as chips separated by spaces. Nothing for an empty value.

    links([{"title": "Search cutover runbook", "url": "#", "icon": "page"}])

### `text(item, key='text')`

A text field, escaped, with its {n} placeholders replaced by smart links.

Data: a plain string, or {"text": "Approved in {0}", "links": [link, ...]}. A single "link" counts as
links[0]. Text in backticks shows as code. key reads another field of the item.

    text({"text": "Raised in {0}", "links": [{"title": "#search", "url": "#", "icon": "hashtag"}]})

### `texts(x)`

One text field or a list of them, as a list, so a lone string isn't read one character at a time. An
empty list for an empty value.

    texts('The cutover moved to Nov 16.')  # ['The cutover moved to Nov 16.']

## status

Lozenges for status and type. Their CSS is in ads.css.

### `lz(item)`

A lozenge, or nothing for an empty value.

Data: {"text": "At risk", "tone": "warning"}, or a plain string for a neutral one. The tone is one of
success, warning, danger, information, discovery and neutral.

    lz({"text": "Blocked", "tone": "danger"})

### `lz_text(item)`

The text of a lozenge given as a dict or a plain string.

    lz_text({"text": "At risk", "tone": "warning"})  # "At risk"

## layout

Page layout: the header, cards, section messages, the footer and the copy button. CSS: layout.css.

CSS: `layout.css`, styling `.btn`, `.card`, `.card-h`, `.copy-fallback`, `.count`, `.counts`, `.eyebrow`, `.fine`, `.ic`, `.ic-disc`, `.ic-subtle`, `.meta`, `.meta-row`, `.mock-note`, `.notice`, `.panel`, `.summary`, `.tabs`, `.tabs-wrap`, `.tag--muted`, `.tags`, `.title-row`, `.title-row__badge`, `.wrap`.

### `header(eyebrow, title, meta, counts='', badge='', lede='')`

The page header: the eyebrow, the page's only h1 with its badge on the right, then the meta line, with its
counts at the right end, then the lede.

meta, counts and badge are HTML. Build each meta item with meta_item. badge holds the page's verdict or the
anchor's own status, as one or more lozenges. counts holds count lozenges, or the page's one action or live
state. lede is a text field: one line of small subtlest text on how the page was made.

    header('Catch-up', 'Search migration', meta_item('calendar', 'Oct 12 to Oct 23'),
           counts=lz({"text": "3 need you", "tone": "warning"}))

### `meta_item(ic, item, tip='')`

One item of a header's meta line: an optional icon, then a text field. tip is a tooltip.

    meta_item('calendar', 'Thu, Oct 29, 2:00 to 2:45 PM PT, in 2 days')
    meta_item(None, {"text": "Atlassian project · {0}", "link": link})

### `link_button(label, url, ic=None)`

A link styled as a default (outlined) button, for a page's one action that opens somewhere else, such as
joining a meeting. Use smart links for everything else.

    link_button('Join Google Meet', 'https://meet.google.com/abc-defg-hij', 'video')

### `card(ic, title, body, extra='', ic_cls='ic-subtle')`

A flat section card with an icon-led heading. body is HTML, and extra adds attributes to the section.

    card('flag', 'Needs you', rows(items, empty_msg='Nothing is waiting on you.'))

### `summary_card(title, paras, generated_from, check='acting on', extra='', lead='', more='')`

The AI summary card: any lead HTML (such as metric tiles), paragraphs as text fields, any more HTML, the
"Generated from" line, then any extra HTML.

    summary_card('While you were away', ['The cutover moved to Nov 16.'], 'Jira, Confluence and Slack')

### `tabs(items, label)`

Tabs: the tab list, then one panel per tab, with the first selected. The page script switches them, with
clicks and the arrow keys, and keeps the choice in the URL hash, and print shows every panel. label names the
tab list for screen readers.

Data: [{"key", "label", "icon", "count"?, "body", "card"?}]. body is HTML, and count shows after the label when
given. With card, the panel is itself a card, for a tab holding one section. Without it, the panel holds cards.

    tabs([{"key": "read", "label": "Read first", "icon": "book", "count": 4, "body": card('book', 'Read first', rows)},
          {"key": "trace", "label": "Trace", "icon": "task", "body": trace, "card": True}], 'Guide sections')

### `empty(msg)`

A line of small subtlest text, for a section with nothing in it.

    empty('No decisions you missed in this window.')

### `note(item, ic='info', tone='', title='', after='')`

A section message holding a text field, with an optional title, and after it an optional text field in
small text. tone is warning, danger, success, information or discovery, for the section message of that kind.

    note({"text": "{0} says the limit is 100.", "links": [link]}, ic='warning', tone='warning',
         title='A support article disagrees with the code')

### `copy_btn(target, label='Copy', cls='btn btn--compact', fallback=False)`

A copy button. target is an element id, or the text itself. With fallback, the text is shown and selected
if the clipboard is blocked.

    copy_btn('notes-md', 'Copy as Markdown')

### `footer(f)`

The sources footer.

Data: {"tags": [{"text", "muted"?}], "lines": [text fields]}. A muted tag is for an app with no results.

    footer({"tags": [{"text": "Jira"}, {"text": "No results from Zoom", "muted": True}],
            "lines": ["Prepared just now, Oct 27, 9:05 AM PT"]})

### `row(x, default_lz=None, source_key='source', when_key='when', label='Source: ')`

A finding row: the lozenge in a fixed left column, the sentence, any excerpt, then the source line.

Data: {"type": lozenge or [lozenges], "text": text field, "links"?, "contact"?, "source": link or [links],
"when"?, "quote"?, "quoteFrom"?}. Several lozenges stack in the left column. contact is a text field shown
under the sentence ("Contact: Riley Novak, Senior engineer"). default_lz is used when the row has no type.

    row({"type": {"text": "Overdue", "tone": "danger"}, "text": "Approve the schema change",

### `numbered(items)`

A numbered list of one-sentence items in medium weight, each with where it came from in small subtlest text.

Data: [{"text": text field, "from": "From Sep 24 sync notes"}]. "from" is plain text, not a link.

    numbered([{"text": "Name an owner for the restore step.", "from": "From the rollback plan"}])

### `link_rows(items, meta='')`

One smart link per row, with a line of small subtlest text under it. meta is the line for a row without one.

Data: [{"link": link, "meta": "Confluence · Marco Ruiz · updated yesterday"}].

    link_rows([{"link": {"title": "Search cutover runbook", "url": "#", "icon": "page"}, "meta": "Confluence"}])

### `checklist(items)`

A list of native checkboxes, each labelled with a text field. Ticks aren't saved.

    checklist(['Has a site admin set an idle timeout?', 'Is the `beacon.session.activity-heartbeat` flag on?'])

### `labelled_rows(items)`

Rows with a label in a fixed left column, then a smart link or a text field, with where it came from under it.

Data: [{"label", "link"? or "text"?, "from"?: text field}].

    labelled_rows([{"label": "Team", "link": {"title": "Team Ledger", "url": "#", "icon": "teams"},
                    "from": "Declared in compass.yml"}])

### `text_rows(items)`

A plain list of text fields, one per row, such as reasons in a record's words with their source chips.

    text_rows([{"text": "“An in-place upgrade needs the cluster offline for 2 days.” {0}", "links": [link]}])

### `rows(items, empty_msg='', **kw)`

A list of finding rows, or the empty message when there are none. Keyword arguments go to row().

    rows(d.get('needsYou'), empty_msg='Nothing is waiting on you.')

## diagram

Dependency diagrams: the wide and tall SVG versions, their legend and the full list. CSS: diagram.css.

The layout is computed here, so a data writer only lists the dependencies. Columns run second-hop upstream,
upstream, the anchor, downstream and second-hop downstream. Arrows point the way work flows, from a
dependency to the work waiting on it. Each column shows at most 7 nodes, most severe first: Done dependencies
collapse into one "N done" node, and the rest past the limit into "+N on track", or "+N more" when they're
mixed. A collapsed node links to the list. Titles are cut at 0.55em per character and refined in the browser
by DIAGRAM_JS, with the full title in each node's <title>. The wide diagram scales down to 85% of its width,
then a container query swaps in the tall version.

CSS: `diagram.css`, styling `.dg`, `.dg-anchor__box`, `.dg-anchor__title`, `.dg-col`, `.dg-edge`, `.dg-edge-at-risk`, `.dg-edge-back`, `.dg-edge-blocked`, `.dg-edge-done`, `.dg-edge-flow`, `.dg-edge-on-track`, `.dg-edge-src-not-recorded`, `.dg-edge-src-related`, `.dg-edge-stale`, `.dg-figure`, `.dg-head`, `.dg-head-at-risk`, `.dg-head-blocked`, `.dg-head-on-track`, `.dg-legend`, `.dg-list`, `.dg-list__wrap`, `.dg-node__bar`, `.dg-node__box`, `.dg-node__meta`, `.dg-node__title`, `.dg-pill`, `.dg-pill-danger`, `.dg-pill-discovery`, `.dg-pill-information`, `.dg-pill-success`, `.dg-pill-warning`, `.dg-pill__text`, `.dg-pill__text-danger`, `.dg-pill__text-discovery`, `.dg-pill__text-information`, `.dg-pill__text-success`, `.dg-pill__text-warning`, `.dg-placeholder`, `.dg-src-not-recorded`, `.dg-st-at-risk`, `.dg-st-blocked`, `.dg-st-on-track`, `.dg-swatch`, `.dg-swatch__box`, `.dg-swatch__box--dashed`, `.dg-tall`, `.dg-wide`.

### `diagram(anchor, deps, kind='project')`

The dependency diagram in a figure: the wide version, and the tall one for narrow containers.

Data: anchor is {"title", "url", "status": lozenge}. Each dependency is {"title", "url", "side": "upstream" or
"downstream", "state", "source"?, "hop"?, "id"?, "feeds"?, "bothWays"?, "team"?, "date"?}. state is one of
blocked, at-risk, stale, on-track, done and unknown. source is recorded (the default), related or
not-recorded. A second-hop dependency has "hop": 2 and "feeds", the id of the first-hop one it feeds. kind
names the anchor's column: project, goal or epic. Use DIAGRAM_JS as the page's js.

    diagram({"title": "Beacon offline editing", "url": "#", "status": {"text": "At risk", "tone": "warning"}},
            [{"title": "Sync conflict resolution service", "url": "#", "side": "upstream", "state": "blocked"}])

### `legend()`

The diagram's legend: each state's colour, each source's line style, and which way the arrows point.

    legend()

### `dependency_list(deps)`

Every dependency as a table in a collapsed <details id="all-deps">, which collapsed nodes link to.

Data: the diagram's dependencies, each with "from", where it came from ("Jira", "Slack").

    dependency_list(deps)

## code

Code: a trace of numbered steps with code chips and excerpts, value pills, a table that stacks on phones,

CSS: `code.css`, styling `.change-row`, `.change-row__version`, `.change-row__when`, `.code-box`, `.code-chip`, `.code-chip--test`, `.code-excerpt`, `.code-gap`, `.code-ln`, `.doc-row`, `.doc-row__meta`, `.stack-table`, `.stack-table__sub`, `.stack-table__wrap`, `.trace`, `.trace-step`, `.trace-step__body`, `.trace-step__chips`, `.trace-step__meta`, `.trace-step__num`, `.trace-step__text`, `.value-pill`, `.value-pill__value`.

A chip linking a file at the cited lines: "idleTimer.ts · lines 8 to 31", with the path and commit in its

A collapsed "Show the code" disclosure: up to 12 lines in monospace with their numbers, an ellipsis row

A small pill for a default or a limit: "Default **30 minutes**".

### `trace(steps, commit='')`

The trace as a numbered list. Each step has its sentence, its kind lozenge and value pill if any, its code
chip and any test chip, then the excerpt.

Data: [{"text": text field, "kind"?: lozenge, "value"?: value pill, "code"?: code chip, "test"?: code chip,
"excerpt"?: excerpt lines}].

    trace([{"text": "The API falls back to the default.", "value": {"label": "Default", "value": "50 invoices"},
            "code": {"path": "api/search/params.py", "lines": [12, 30], "url": "#"}}], commit='4e91c07')

### `stack_table(headers, rows)`

A table whose rows become stacked blocks at 600px and narrower, each cell under its label, so a long
setting name keeps the full width. Cells are text fields, or {"text", "sub"} with a small line under it.

    stack_table(['Setting or flag', 'What it changes', 'Who controls it'],
                [[{"text": "`pageSize`", "sub": "Request parameter"}, "How many invoices a page holds", "The caller"]])

### `doc_rows(items)`

Findings from docs and chat as stacked items: the smart link on its own line, the claim, then its lozenge
and what it was checked against, so long titles don't squeeze the claim.

Data: [{"link": link, "claim": text field, "verdict": lozenge, "meta": "Runbook · Updated Aug 19, 2026"}].

    doc_rows([{"link": {"title": "Ledger search API reference", "url": "#", "icon": "page"},
               "claim": "Says the default page size is 100.", "verdict": {"text": "Disagrees", "tone": "danger"}}])

### `change_rows(items)`

Recent changes: the version and date in a column, then the line and its link.

Data: [{"version"?, "date", "text": text field, "link"?}].

    change_rows([{"version": "2.12", "date": "Aug 4, 2026", "text": "Lower the default page size to 50.",
                  "link": {"title": "ledger-api: smaller default search pages", "url": "#", "icon": "pull-request"}}])

## decisions

Decisions: decision blocks with their fields, options considered, and a vertical timeline. CSS: decisions.css.

CSS: `decisions.css`, styling `.decision`, `.decision__fields`, `.decision__heading`, `.decision__how`, `.decision__quote`, `.option`, `.option__name`, `.timeline`, `.timeline__body`, `.timeline__date`, `.timeline__text`.

### `decision(x)`

One decision in the chain, headed with what it is and its status, then its fields: Decided (the record's
words, quoted, with its link), When and Who decided (each with how it's known), and Also recorded.

Data: {"heading", "status": lozenge, "decided", "link", "when", "whenHow"?, "who", "whoHow"?, "also"?: [links],
"alsoHow"?}.

    decision({"heading": "Newest decision", "status": {"text": "Decided", "tone": "success"},
              "decided": "Cut over on Nov 16.", "link": {"title": "Search migration decision log", "url": "#", "icon": "page"},
              "when": "Decided on Oct 16, 2026", "whenHow": "decision log row", "who": "Amara Lindqvist"})

### `options(items)`

Options considered, one row each: the record's name for it, a short description in its words, and a
"Chosen" or "Recommended" lozenge.

Data: [{"name", "text", "chosen"?, "recommended"?}].

    options([{"name": "Build a new cluster.", "text": "Run both clusters and switch traffic.", "chosen": True}])

### `timeline(items)`

A vertical timeline, oldest first: the date (or "No date"), the type lozenge, one sentence and its smart
link. At 600px and narrower each date sits above its item.

Data: [{"date"?, "type": lozenge, "text": text field, "link"?}].

    timeline([{"date": "Jun 12, 2026", "type": {"text": "Recorded decision", "tone": "success"},
               "text": "The DACI was marked Approved.", "link": {"title": "DACI: Search cluster upgrade path", "url": "#", "icon": "page"}}])

## board

Boards: an interactive board of work items to select and start sessions from. CSS: board.css.

The page carries its data and renders the cards in the browser, so the filter, the toggles, selection, the dock
and the live refresh all work on the same list. The board scrolls inside its own box, never the page.

CSS: `board.css`, styling `.board-card`, `.board-card--epic`, `.board-card__key`, `.board-card__meta`, `.board-card__open`, `.board-card__title`, `.board-card__type`, `.board-col`, `.board-col__count`, `.board-col__empty`, `.board-col__head`, `.board-cols`, `.board-dock`, `.board-dock__in`, `.board-dock__row`, `.board-field`, `.board-input`, `.board-out`, `.board-scroll`, `.board-state`, `.board-state--live`, `.board-state__dot`, `.board-toggle`, `.board-tools`.

### `board_state()`

The snapshot or live state pill, for the right of the page header. The script keeps it up to date.

    k.header('Work board', d['boardName'], meta, counts=k.board_state())

### `board(d)`

The board: the toolbar (repo field, filter, Hide Done and Hide epics toggles, Refresh), the columns the
script fills, the snapshot line, and the dock for the selected items' commands. Put board_state() in the
header, and pass board_script(d) as the page's js.

Data: {"site", "cloudId", "boardId", "boardName", "boardUrl", "jql", "connector", "builtAt", "columns": [{"name",
"statuses", "done"}], "issues": [{"key", "summary", "status", "type", "priority", "assignee"}]}.

    k.page(d['boardName'], k.board(d), js=k.board_script(d), width='board')

### `board_script(d)`

The board's page script, with the data and the connector's display name in front of it.

    board_script({"connector": "Atlassian Rovo", ...})
